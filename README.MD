# CompSTEAM: TV boxes reaproveitadas na escola

**CompSTEAM** transforma TV boxes (TX9, MXQ Pro e BTV11) em computadores para escolas, com Android TV e Linux (Debian 13), instalados pela própria TV.

- Página do projeto: https://rbeninca.github.io/tvbox/
- Apresentação do projeto: https://rbeninca.github.io/tvbox/apresentacao/
- Documentação técnica: [docs/](docs/README.md)
- Instalador do TX9 (zip para o cartão): https://github.com/rbeninca/tvbox/releases/tag/instalador-tx9-1.2.45
- Instalador do MXQ Pro (imagem para o cartão microSD): https://github.com/rbeninca/tvbox/releases/tag/instalador-mxq-1.2.46
- Instalador do BTV11 (zip para o pendrive): https://github.com/rbeninca/tvbox/releases/tag/instalador-btv11-1.2.45
